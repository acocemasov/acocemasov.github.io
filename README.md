# Portfolio Page

Minimal one-screen portfolio built with React, TypeScript, Vite and Material UI.

## Highlights

- Interactive 3D link orbit for Email, GitHub, Scholar, CV and LinkedIn.
- Animation is **pure CSS** (`transform`, `perspective` and `keyframes`).

## Scripts

- `npm install`
- `npm run dev`
- `npm run lint`
- `npm run build`

## Tech Stack

- React + TypeScript
- Vite
- Material UI

## Deploy (GitHub Pages)

- Use a **user-site repo** named `akocemasov.github.io`.
- Push to `main` to trigger deployment via GitHub Actions.
- In GitHub repo settings, set **Pages → Source** to **GitHub Actions**.
- Site URL will be `https://akocemasov.github.io/`.
